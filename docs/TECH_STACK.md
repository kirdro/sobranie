# Технологический стек

## Next.js
- Используем версию 15 с App Router и серверными компонентами.
- Рендерим дизайн-систему через маршруты в `app/`, настраиваем метаданные и оптимизацию картинок из коробки.

## React
- Актуальная версия 19, что позволяет применять актуальные хуки и улучшения рендера.
- Клиентские компоненты помечаем директивой `"use client"`, состояние храним локально либо выносим в Effector.

## Tailwind CSS
- Работаем с `tailwind.config.ts` и кастомными токенами для цветовой палитры Собрания.
- Соблюдаем атомарный подход: повторяющиеся наборы классов выносим в компоненты или утилиты.

## Effector
- Основное средство управления состоянием и бизнес-логикой.
- Создаём сторы и эффекты для межстраничных сценариев, синхронизируем данные между сервером и клиентом.

## @tanstack/react-query
- Используем для запросов и кеширования, когда Effector не закрывает потребности по синхронизации с сервером.
- Конфигурируем провайдер в `app/providers.tsx`, подключаем хуки `useQuery`/`useMutation` для работы с API.
