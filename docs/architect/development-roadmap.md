# План развития социальной сети Sobranie

## Текущее состояние проекта

### ✅ Что уже реализовано и работает

1. **Аутентификация и авторизация**
   - Регистрация и вход через API (реальные данные)
   - Cookie-based сессии с токенами
   - Защищенные роуты и middleware
   - Роли пользователей (user, admin, moderator)

2. **Базовая инфраструктура**
   - Next.js 15 с App Router
   - TypeScript с строгой типизацией
   - Tailwind CSS с футуристической темой
   - API клиент с обработкой ошибок
   - React Query для серверного состояния

3. **Частично работающие функции**
   - **Лента постов** - загружаются с API, но создание только начато
   - **Круги (сообщества)** - загружаются с API, отображается список
   - **Уведомления** - загружаются с API для авторизованных
   - **Профиль пользователя** - отображает данные, но редактирование не работает

### ⚠️ Что использует моковые данные

1. **Компонент FeedComposer**
   - Создание постов начато, но не завершено
   - Effector stores упоминаются, но не реализованы

2. **ActivityStream в ленте**
   - Если нет данных с API, показывает fallback контент
   - Преобразует посты в активности, но не все поля доступны

3. **LLM Ассистент**
   - Полностью эмулирован (функция `emulateLLM`)
   - Источники контекста захардкожены
   - Нет реальной интеграции с AI

4. **Статические данные в компонентах**
   - Петли взаимодействия в FeedShell
   - Служба сигналов в FeedShell
   - План на неделю в CirclesShell
   - Режимы проводника в LlmShell

### ❌ Что не реализовано

1. **Effector state management**
   - Файлы импортируются, но не существуют
   - Нужно создать stores, events, effects

2. **Реальная функциональность**
   - Создание и удаление постов
   - Комментарии к постам
   - Лайки и репосты
   - Подписки на пользователей
   - Членство в кругах
   - Загрузка медиафайлов
   - Поиск по контенту
   - Настройки приватности

3. **Профиль пользователя**
   - Редактирование профиля не сохраняется
   - Статистика захардкожена (всегда 0)
   - Нет аватаров

## Технические долги

1. **Создать Effector stores**
   - `$user`, `$posts`, `$isAuthenticated`
   - events: `postCreated`, `userLoggedIn`
   - effects: `createPostFx`, `fetchPostsFx`

2. **Типизация API**
   - Дополнить types.ts недостающими типами
   - Добавить валидацию ответов

3. **Обработка ошибок**
   - Глобальный error boundary
   - Retry логика для API

4. **Тестирование**
   - Unit тесты для компонентов
   - E2E тесты основных flows

5. **Документация**
   - API документация
   - Компонентная библиотека
   - Руководство контрибьютора
