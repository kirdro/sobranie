# Чек-лист реализации нового дизайна

## Подготовка
- [x] Внимательно изучите стиль и требования в [docs/description.md](./description.md); зафиксируйте ключевые паттерны (тёмная палитра, футуристические градиенты, 3D-акценты, минимализм).
- [x] Держите в фокусе обязательные правила из [docs/ARCHITECTURE_GUIDELINES.md](./ARCHITECTURE_GUIDELINES.md); заранее распланируйте декомпозицию файлов, чтобы не превышать 300 строк.
- [x] Сверьтесь с [docs/TECH_STACK.md](./TECH_STACK.md); убедитесь, что компоненты и состояние планируются с учётом Next 15, React 19, Tailwind, Effector и React Query.

## Анализ референса
- [x] Изучите визуальный референс `docs/images/design.png`; определите блоки (левое меню, центральная лента, правый сайдбар) и адаптируйте их под разделы «Собрания»: `Главная`, `Поток`, `ИИ-проводник`, `Сообщества`, `Уведомления`.
- [x] Зафиксируйте основные визуальные элементы: неоновые обводки, мягкие тени, круглые аватары, футуристические иконки.
- [x] Распределите сетку: левый навбар ~20%, центральная лента ~50%, правый сайдбар ~30% ширины.

## Проработка визуального языка
- [x] Подготовьте токены цветов и градиентов в `tailwind.config.ts`, чтобы избегать инлайновых значений.
- [x] Настройте типографику: заголовки — футуристичный акцентный шрифт, тело — читаемый гротеск; сохраните иерархию размеров как в референсе.
- [x] Используйте CSS-переменные/Tailwind-утилиты для glow-эффектов, рамок и hover-состояний; протестируйте на тёмной теме и высокой контрастности.

## Компонентная структура
- [x] Разбейте экран на композиционные компоненты: `SidebarNav`, `FeedCard`, `TrendsPanel`, `WhoToFollow`, `AiPromptInput` и т.д., помещая общие элементы в `components/common`.
- [x] Создайте хуки или Effector-stores для данных навигации, трендов и подсказок; вынесите сетевой слой в React Query при необходимости.
- [x] Убедитесь, что каждый файл остаётся коротким; при сложной логике выносите вспомогательные компоненты/функции в отдельные файлы или `lib/`.

## Контент и данные
- [x] Подготовьте мок-данные для прототипа (аватары, теги, статистика) и расположите их в `lib/` или Effector store; избегайте жёсткого дублирования.
- [x] Обеспечьте возможность локализации: тексты храните в конфигурациях или словарях.
- [x] Продумайте состояние загрузки и пустые состояния для ленты, рекомендаций и подсказок.

## Интерактивность и UX
- [x] Реализуйте плавные ховеры и focus-стили для навигации и карточек; соблюдайте требования доступности (ARIA-атрибуты, контраст ≥4.5:1).
- [x] Добавьте микро-анимации (например, подсветка карточки при наведении) через Tailwind transitions или Framer Motion, сохраняя производительность.
- [x] Встроите поле быстрого запроса к ИИ с визуальными индикаторами активности (пульсирующее свечение, индикатор загрузки).

## Проверки
- [ ] Прогоните `bun run lint` и `bun run build`; убедитесь, что Next 15 не выдаёт предупреждений о несовместимостьх.
- [ ] Проверьте адаптивность: ≥1440px (desktop), ~1024px (tablet), 768px и менее (mobile); элементы должны оставаться читаемыми.
- [ ] Пройдитесь по чек-листу дизайна из [docs/description.md](./description.md) и зафиксируйте соответствие (цвета, 3D-акценты, футуристическая атмосфера).
- [ ] Задокументируйте отличия от референса и причину изменений в PR; приложите скриншоты ключевых экранов.
